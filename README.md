# SLS — Sales Lead System

Статический лендинг закрытого сообщества SLS.

## Локальный запуск

Откройте папку `dist` через любой статический HTTP-сервер. Главная страница — `dist/index.html`.

## Telegram для кнопок покупки

Укажите Telegram username Льва в константе `TELEGRAM_USERNAME` в начале файла `dist/script.js`. Без username кнопка открывает стандартное окно Telegram с готовым текстом заявки и выбором чата.
